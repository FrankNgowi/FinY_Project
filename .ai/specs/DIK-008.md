# DIK-008: Dikonekti launcher icon in the Flutter app

## Summary
Replace the default Flutter launcher icon on Android, iOS, the Flutter web build, Windows and macOS with the Dikonekti mark (white Material `volunteer_activism` glyph on the app's purple gradient, as on the login screen and the web favicon). The art is drawn once from two small SVG sources into two 1024 px PNGs (a full-bleed icon, and a transparent glyph-only layer for Android's adaptive icon), and the platform files are generated by the `flutter_launcher_icons` package from a configuration in `pubspec.yaml`, so the icons can be regenerated when the logo changes. The generated files are committed, so building the app never needs the tool or the SVG renderer. Key trade-off: the generator needs a Flutter SDK, which is not installed on this machine; the plan installs one (it is also what DIK-005 will need), and falls back to a script-made set of files if that is declined.

## Implementation Steps
1. **Install the Flutter SDK** (needs approval, see the checkpoint): `git clone https://github.com/flutter/flutter.git -b stable ~/flutter`, then `flutter --version`, turn off analytics for this install, `flutter doctor` to confirm the Android toolchain. Nothing is added to shell profiles; commands use the full path.
2. **Baseline before any change**: `flutter pub get`, `flutter analyze`, `flutter test` in `dikonekti/`, recording counts, so pre-existing problems are known and not blamed on this ticket.
3. **Draw the art**: write `assets/icon/app_icon.svg` (1024 square, diagonal gradient `#6750A4` to `#9B7FE8`, the glyph white and centred at about half the width) and `assets/icon/app_icon_foreground.svg` (transparent, the same glyph centred and sized to stay inside Android's 66 dp safe circle of the 108 dp canvas, about 40 percent of the width). Render each to a 1024 px PNG with headless Chrome (ImageMagick's built-in SVG renderer drops the gradient), then check size, colours and transparency.
4. **Configure the tool**: `pubspec.yaml` gets `flutter_launcher_icons` as a dev dependency and a `flutter_launcher_icons:` block (`image_path` the full icon; Android adaptive background `#6750A4` and the foreground PNG; iOS with alpha removed; web, Windows and macOS generation on). Run `flutter pub get`.
5. **Generate**: `dart run flutter_launcher_icons`. Review `git diff --stat` and each touched manifest or `Contents.json`; revert anything unrelated.
6. **Hand edits**: `web/manifest.json` (`name` and `short_name` "Dikonekti"; the tool sets the colours) and `web/index.html` (`<title>`, Apple title).
7. **Write `assets/icon/README.md`** and the `.ai/context.md` regeneration note.
8. **Verify** (see QA): file checks, adaptive-icon mask previews, `flutter analyze`, `flutter test`, `flutter build apk --debug`, `flutter build web`.

## Professional Practice
[Android's adaptive icon guidance](https://developer.android.com/guide/practices/ui_guidelines/icon_design_adaptive.html): both layers are 108 dp square, the background must be opaque, the foreground may be transparent, and a centred 66 dp area is never clipped by any manufacturer mask. Adopted: solid-colour background layer, glyph-only transparent foreground sized to stay inside the safe circle. The exact `flutter_launcher_icons` option names (`adaptive_icon_background`, `adaptive_icon_foreground`, `remove_alpha_ios`) are from the package's documentation as I know it, and the search did not confirm them; step 4 checks them against the package's own README once the package is downloaded.

## Risks & Gotchas
- **No Flutter SDK on this machine.** Without one, the tool, `pub get`, `analyze` and the build cannot run, and `pubspec.lock` cannot be updated by hand (it needs package hashes). Fallback if the install is declined: generate the same files with a script using ImageMagick, leave `pubspec.yaml` unchanged, and mark the build and analyze criteria as not verified.
- **The Dart constraint is `^3.11.5`**, so a current Flutter stable is required; the cloned stable branch must report Dart 3.11.5 or newer.
- **The tool overwrites files and may edit** `AndroidManifest.xml` or `Contents.json`; review the diff and keep only icon changes.
- **iOS rejects icons with an alpha channel**: the source is opaque and `remove_alpha_ios` is on; the files are checked.
- **Adaptive icon cropping**: the outer third of the foreground can be cut by a mask; the glyph is sized to the safe circle and previewed in three mask shapes.
- **Existing icon files are small (the web favicon is 16 px, the manifest icons plain)**: the tool's outputs replace them; the maskable web icons are full-bleed and are checked to keep the glyph inside the safe zone.
- The first `flutter` run downloads the Dart SDK and engine artifacts (about 1 to 2 GB); the first Android build downloads Gradle and dependencies.

## Decisions during implementation
- **Flutter version.** Flutter 3.50 (newest stable) was installed first and failed the Android build: it requires Gradle 9.3.1 and the project is on Gradle 8.14 with AGP 8.11.1, and it also rewrote `pubspec.lock` (7 unrelated bumps), `analysis_options.yaml` and `android/gradle.properties` on its own. The SDK in `~/flutter` was switched to **3.41.9 (Dart 3.11.5)**, the line the project's lock was made with. With it, `pub get` only adds the icon tool and its five dependencies (`archive`, `checked_yaml`, `cli_util`, `flutter_launcher_icons`, `image`, `posix`) and nothing else changes on its own.
- **JDK.** Flutter picked Android Studio's bundled Java 25, which Gradle 8.14 rejects; `flutter config --jdk-dir=/usr/lib/jvm/java-21-openjdk-amd64` points this Flutter install at the system JDK 21.
- **Generator bug reverted.** `flutter_launcher_icons` 0.14.4 rewrote `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = YES` to `= AppIcon` in `ios/Runner.xcodeproj/project.pbxproj`; that change is unrelated and invalid, so the file is left untouched (documented in `assets/icon/README.md`).
- `adaptive_icon_foreground_inset: 0`: the tool's default 16 % inset would have shrunk the glyph to about 27 % of the canvas; the layer is already sized for the 66 dp safe circle.
- The tool adds legacy iOS sizes (50, 57, 72) and their files to the catalog; nothing was dropped.
- `web/index.html` `<title>` and Apple title now say "Dikonekti" (consistency with the manifest); `assets/icon/` is not listed under `flutter: assets:` (not bundled).
- The legacy round Android icon is not generated by the tool (only the square one), as noted in the plan.
